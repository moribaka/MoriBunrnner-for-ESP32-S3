# v2.32.111：GBC 电压直接入口

网页入口移动到“烧录中心 → GB/GBC”模式按钮正下方，选择 3.3V/5V 后只提交
`gbc_voltage`，自动保存，下次卡带操作生效。GBA 模式隐藏该控件；原设备设置的
电压下拉框移除，核心分配的读取和保存不再依赖或覆盖该控件。

机身“烧录器 → GBC”第二行显示“GBC 电压: 3V3/5V”，按 A 切换并保存。
分析前后均可访问；从深层设置删除重复电压行。GBC 主菜单数量由实际操作映射计算，
修正此前分析后遗漏设置行的问题，分析后共 12 行。存储失败保留错误提示并恢复内存设置。
本次没有改变电源切换时序、Bacon/AG32 协议或时钟，也没有将此前未复现的关机宣称为已修复。
