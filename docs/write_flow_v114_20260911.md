# v2.32.114：烧录完成即结束，校验保持独立

用户要求优化独立校验和 dump，并明确拒绝 v113 擅自加入的烧后全量校验。
本次删除该阶段，而非添加开关或保留默认关闭的额外分支。

## 修改边界

- 删除 ROM 烧录任务尾部的自动校验调用及专用 expected-readback 包装。
- 删除自动校验计时/字节/计划/活动状态字段、HTTP 输出、网页展示及机身结果行。
- 进度恢复为烧录自身的 0–100%，写入和总耗时在烧录结束时冻结。
- 独立校验及其测试恢复到 `641f4e6` 的完整逐字节比较版本。
- dump 流水线、扇区写入优化、补丁应用、头校验修正和电源收尾保持现有实现。
- AG32 固件刷写校验与卡带 ROM 操作分属不同流程，本轮未更改 AG32 刷写。
- 调试 skill 明确三个用户操作独立；测试工具主动启动独立校验不等于设备自动校验。

## 验证

IDF v5.5.1 编译通过；GCC 计时回归覆盖 50%/100% 原样显示及完成后耗时冻结。
生产 dump/verify 主机回归覆盖异步缓存所有权、奇数长度、边界、精确不匹配和
失败清理。Web 脚本/状态轮询、GBC 补丁隔离、共享状态结构测试均通过。

更新前先尝试与上轮备份比较，在 0xA0 得到 44->4D，不匹配；串口也记录到
用户操作过机身。因此没有用旧备份恢复当前游戏，而是先另存当前前 32 MiB。
这条预检失败不是 v114 回归失败，也没有触发重写。

当前卡内标题为 `MOTHER3`，头校验 DB 与计算值一致。实机结果：

| 独立操作 | 大小 | 任务耗时 | 结果 |
|---|---:|---:|---|
| dump 当前内容 | 32 MiB | 25.045 秒 | TF 输出完成 |
| 校验这份 dump | 32 MiB | 22.290 秒 | 全部字节一致 |
| 机身同内容烧录 | 32 MiB | 24.640 秒 | 匹配全部字节，0 擦除、0 编程，直接结束 |

备份位于 TF `ROM_OUTPUT/v114_current_gba.gba`。机身烧录结果 progress=100、
verify_sample_valid=false，API 已无自动校验字段；串口该次没有 ROM verify
阶段。测试脚本返回主页。主机计时测试同时确认烧录进度不会再被压缩至 80%。
本轮卡带内容未改动；测试完成恢复 auto 链路。GBC 共用任务调度和状态代码，
本轮未要求换卡重跑 GBC 写入。前一版同数据成绩来自另一镜像，不作为同 ROM 提速倍数依据。
