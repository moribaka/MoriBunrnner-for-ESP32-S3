# 烧录页卡带信息导航

GBA/GBC 烧录页现在支持左右键查看卡带信息：左键回到简要信息，右键展开详细
NOR 信息。简要页只显示卡带类型、识别到的芯片型号和容量，并提示右键查看详情；
详细页保留 CFI/NOR ID、扇区、缓冲区、映射、保存类型和补丁信息。

本次只改 UI 导航和显示，不改变 mapper 探测、MBC3/MBC5 烧录流程、擦除时序或
烧录协议。芯片型号来自现有 CFI/ID 数据库；若数据库无法区分同系列后缀，页面
显示数据库已有的通用型号，不猜测 N/P/S 后缀。

主应用已增量编译并刷入 `0x20000`，esptool 报告 `Hash of data verified`；刷写后
MoriBurnner UI 正常启动。当前改动尚未重新打包完整 ZIP。
