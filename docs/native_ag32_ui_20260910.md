# 机身 AG32 固件更新

入口：**系统 → 设置 → AG32固件更新**。

将 `moriburnner_ag32_batch.bin` 放到 TF 卡根目录或子目录，关闭 USB 直通，
停止正在进行的烧录/播放任务。在机身菜单选择“选择AG32固件”，进入目录并
选择 `.bin`。校验通过后显示文件名、记录数和数据量；选择“开始更新AG32”，
再选择“确认刷写AG32”。确认页面默认选中“取消”。

ESP32 通过现有板载 SWD 刷写 AG32 MCU 和 CPLD。更新期间显示阶段、百分比、
已写入和已校验字节，保持屏幕活动，拦截返回、菜单和导航操作。
完成后显示“AG32更新成功”；失败时显示错误信息，不自动重试。
网页和串口更新入口继续使用同一后端。

## 实现

- `main/ui_ag32_update.inc` 负责校验任务、确认交互、后端调用和进度快照。
- 校验在独立任务执行，UI 线程只更新模型和绘制现有列表。
- 复用 TF 目录浏览器，只显示目录和 `.bin` 候选；格式由 AG32 parser 校验。
- 使用现有 `ag32_batch_validate_path` / `ag32_batch_program_start`，没有复制烧录逻辑。
- 新页面加入按键映射表，并增加页面数量与按键映射数量的编译期检查。
- 增加中文文本；英文界面使用对应英文标签。

| 刷写期间 B、Menu、Right | 进度页保持不变，后台继续运行 |
| 最终完成与返回设置 | 显示“AG32更新成功”，返回设置正常 |
