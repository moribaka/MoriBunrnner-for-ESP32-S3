MORI 烧录器 IP 扫描

这个工具不需要刷固件，也不需要往设备里放额外文件。 它会直接遍历局域网 IP，检查哪些地址有 HTTP 响应，扫到后可以直接打开网页。

快速入口：如果板子退回了配网 AP 模式，连接开放热点 SSID MORI-GBA-SETUP（无需密码）， 然后打开 http://192.168.4.1/。
盲扫模式只能知道某个 IP 对 HTTP 有响应，不能 100% 证明它一定是你的 ESP32。 如果你的局域网里还有路由器、打印机、NAS、摄像头之类，也可能一起被扫出来。
